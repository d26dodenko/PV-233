# Происхождение компонентов

React-интерфейс `frontend/` адаптирован из
[Sajid788/edgistify-Assignment](https://github.com/Sajid788/edgistify-Assignment),
коммит `1f0a32adea63c9e5a06c8f6e736491db6b61ae61`.
Автор исходного проекта: Md Sajid Ansari (Sajid788).
README исходного репозитория указывает MIT; отдельного LICENSE в полученном
дереве нет. Исходная декларация сохранена в `third-party/edgistify-README.md`.
Настоящий репозиторий не меняет лицензионные условия upstream и не присваивает
авторство его интерфейса. Перед внешним распространением следует получить
полный текст разрешения и copyright notice у автора.

Адаптация: относительный `/api`, локальный Rust backend вместо Node/MongoDB,
поиск, доступные имена полей, корректные типы TypeScript, ограничение количества,
серверный logout, локальная иллюстрация товара, оформление и подпись автора
учебной работы, согласованные денежные обозначения.
Исходный backend не копировался; Rust backend написан для лабораторной работы.

Остальные зависимости устанавливаются менеджерами пакетов. Точные версии и
контрольные суммы зафиксированы в `Cargo.lock`, `uv.lock` и двух `package-lock.json`.
Условия лицензирования каждой зависимости сохраняются в её пакете.
