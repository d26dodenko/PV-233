# Frontend Moroz Store

React UI адаптирован из Sajid788/edgistify-Assignment; [происхождение](../THIRD_PARTY.md).
Команды из корня репозитория:

```bash
npm --prefix TestingPS/Laba-3/frontend ci
npm --prefix TestingPS/Laba-3/frontend run lint
npm --prefix TestingPS/Laba-3/frontend run build
```

Rust обслуживает собранный `TestingPS/Laba-3/frontend/dist` на порту 3000.
Для разработки `npm --prefix TestingPS/Laba-3/frontend run dev`: Vite 5173 проксирует `/api` на 3000.
Полный запуск и тесты описаны в [главном README](../../../README.md).
