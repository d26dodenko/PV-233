# Лабораторная работа №1

**Тема:** Составление тест-кейсов для готового кода. Качество ПО и место тестирования в жизненном цикле.

## Цель работы

Изучить роль тестирования в обеспечении качества ПО, проанализировать готовую функцию, разработать тест-кейсы и реализовать автоматизированные проверки с помощью Python и `pytest`.

## 1. Описание тестируемой функции

Для исследования выбрана функция `calculate_ticket_price(age, day, is_student)` из файла `tickets.py`. Она рассчитывает цену билета в кино с учётом возраста зрителя, дня недели и студенческого статуса.

### Бизнес-правила

1. Базовая стоимость билета в будние дни (`weekday`) — 400 руб.
2. Базовая стоимость билета в выходные (`weekend`) — 500 руб.
3. Дети младше 6 лет проходят бесплатно.
4. Посетителям от 6 до 17 лет включительно предоставляется скидка 50%.
5. Студентам от 18 лет предоставляется скидка 25%.
6. Детская и студенческая скидки не суммируются.
7. Возраст — целое число от 0 до 120 включительно; при неверном типе возникает `TypeError`, при выходе за диапазон — `ValueError`.
8. Для дня допустимы только `weekday` и `weekend`; иное значение вызывает `ValueError`.
9. Студенческий статус должен иметь тип `bool`; иначе возникает `TypeError`.

### Входные и выходные данные

| Параметр | Тип | Допустимые значения | Назначение |
|---|---|---|---|
| `age` | `int` | 0–120 | Возраст посетителя |
| `day` | `str` | `weekday`, `weekend` | День посещения |
| `is_student` | `bool` | `True`, `False` | Студенческий статус |
| Возвращаемое значение | `float` | 0 и положительные значения | Итоговая цена билета в рублях |

### Классы эквивалентности

- Для возраста: меньше 0 (невалидный); 0–5 (бесплатно); 6–17 (детская скидка); 18–120 (взрослый тариф или студенческая скидка); больше 120 (невалидный); нецелочисленный тип (невалидный).
- Для дня: `weekday` (будний тариф); `weekend` (выходной тариф); любое другое значение (невалидный класс).
- Для студенческого статуса: `True` (студент); `False` (не студент); не-`bool` (невалидный класс).

**Основные границы:** возраст −1/0; 5/6; 17/18; 120/121. Проверяются оба значения дня и оба значения студенческого статуса.
