## 2. Практическая часть

### 2.1. Проект и задачи

Объект тестирования и оценки - учебный калькулятор на Python. Модуль `calculator.py` выполняет четыре арифметические операции, определяет знак числа и проверяет входные данные.

В проекте «Лабораторная № 1» в Аспро.Cloud создано 12 задач.

![Задачи проекта в Аспро.Cloud](img/aspro.png)

### 2.2. Unit-тесты и покрытие

В `test_calculator.py` проверяются арифметика, выбор операции, знак числа, деление на ноль, недопустимые типы, бесконечности и NaN.

Тесты запущены через `pytest` с замером покрытия в `coverage.py`. Все **33 теста** прошли. Они выполнили **36 из 36 исполняемых строк** файла `calculator.py`. Покрытие по строкам составило **100 %**.

![Запуск unit-тестов и замер покрытия](img/coverage.png)

### 2.3. Размер и цикломатическая сложность

LOC (Lines of Code) - метрика размера программы в строках. В работе используется физический LOC: учитываются все строки `calculator.py`, включая пустые. Файл тестов в расчёт не входит. Для каждого диапазона количество строк считается по формуле «последний номер - первый номер + 1». Например, функция `validate_number` занимает строки с 6-й по 12-ю: 12 - 6 + 1 = 7.

| Строки | Содержимое | Количество |
|---|---|---:|
| 1, 3 | Описание модуля и импорт | 2 |
| 6–12 | `validate_number` | 7 |
| 15–16 | `add` | 2 |
| 19–20 | `subtract` | 2 |
| 23–24 | `multiply` | 2 |
| 27–32 | `divide` | 6 |
| 35–43 | `classify_number` | 9 |
| 46–57 | `calculate` | 12 |
| 2, 4–5, 13–14, 17–18, 21–22, 25–26, 33–34, 44–45 | Пустые строки | 15 |

**LOC = 2 + 7 + 2 + 2 + 2 + 6 + 9 + 12 + 15 = 57.** Без пустых строк: **57 - 15 = 42**.

В `classify_number` два условия (`x > 0` и `x == 0`), поэтому **V(G) = 2 + 1 = 3**.

В графе функции семь узлов: вызов проверки аргумента, два условия, три возврата и общий выход. Между узлами восемь рёбер, компонента связности одна. **V(G) = E - N + 2P = 8 - 7 + 2 × 1 = 3**. Рассмотрен поток управления внутри самой функции.

Radon подтвердил результат для `classify_number`: **A (3)**.

![Результат Radon: сложность classify_number равна 3](img/radon.png)

### 2.4. Дефектность и время реакции

Зарегистрирован дефект Q-14. Вызов `classify_number(10**400)` должен вернуть `positive`. Фактически возникает `OverflowError` при преобразовании целого числа в `float` внутри `math.isfinite`. Время первого ответа по карточке не фиксировалось.
